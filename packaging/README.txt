MEGA65 GUI {VERSION}
Created by Chris Freeman - https://github.com/freemchr/mega65gui

Run Mega65Gui.exe. No installation and no .NET download are needed (Windows 10/11, 64-bit).
Windows SmartScreen may warn that the app is from an unknown publisher, because it is not
code-signed yet: choose "More info" and then "Run anyway".

Settings, downloads, backups and reports are kept in %LOCALAPPDATA%\Mega65Gui.

Report problems or ideas: https://github.com/freemchr/mega65gui/issues
